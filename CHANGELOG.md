# Changelog

## 1.0.0
- Initial release.
- Walkthroughs: explain lines, a function, a file or a folder step by step beside the code, with flow, sequence and state diagrams. Each step can be made simpler, deeper or line by line, or you can ask your own question.
- Architecture overview: how the project works, every component and how they connect, use cases with sequence diagrams, lifecycles as state diagrams, and the data model as an ER diagram.
- System map: the project's components and what passes between them, with Explain and Ask for each part.
- Review changes: staged changes (with a suggested commit message), any commit, your branch compared with main, or a GitHub pull request.
- Plan a change: integration points, affected components, risks and an order of work, against your real code.
